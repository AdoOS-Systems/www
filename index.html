Explicit Project Scope & Boundaries

What AdoOS is — and what it intentionally avoids

No glibc Runtime Layer Pure musl libc. Gcompat is available for basic C sonames, while glibc desktop software is targeted through Flatpak & distrobox rather than host mutations.
No Custom Binary Repository AdoOS builds no binary packages of its own. It directly uses upstream Alpine main/community repositories, eliminating sync latency and supply-chain risk.
Live ISO System (No Installer) Designed as a stateless exploration and developer Live environment booted from RAM. There is no disk installer or Calamares wizard.
Open Graphics Only No proprietary NVIDIA / CUDA drivers are bundled. The graphics stack relies entirely on modern open-source drivers (nouveau / NVK / Mesa).
