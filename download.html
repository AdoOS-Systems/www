Rootless Build Engine

Compile the AdoOS Live ISO

AdoOS is distributed as clean source recipes. The ISO is produced directly by Alpine’s native mkimage.sh inside an unshare user namespace without requiring root privileges.

Live ISO Tree Alpine 3.24.1 Base musl libc • OpenRC • abo 3.0.6
1. Standard Rootless Build
(•̀ᴗ•́)و

Clone the repository and run the build script on any modern Linux host. It downloads an isolated official Alpine minirootfs, validates its SHA-256 hash, and generates the ISO:

scripts/build-iso.sh
# Resulting ISO and hashes are output to ./iso:
iso/adoos-3.24.1-x86_64.iso
iso/adoos-3.24.1-x86_64.iso.sha256
iso/adoos-3.24.1-x86_64.iso.sha512
Lite Build (Drop Firmware)

Set the ADOOS_LITE=1 environment variable to exclude heavy linux-firmware packages from the modloop.

ADOOS_LITE=1 scripts/build-iso.sh
Run Under QEMU (Headless)

The serial console is active by default (ttyS0,115200), making instant testing possible without a display server:

qemu-system-x86_64 -cdrom iso/adoos-*.iso -m 1G -nographic

Build Target Specifications

Architecture x86_64
Kernel Flavor Alpine linux-lts
Package Manager abo 3.0.6 (musl)
Base Distribution Alpine 3.24.1

Notice Regarding Prebuilt Binaries

AdoOS does not distribute unverified binary blobs on random mirrors. The build pipeline is fully deterministic: by running the script yourself, you verify upstream Alpine minirootfs SHA-256 signatures directly on your machine.
